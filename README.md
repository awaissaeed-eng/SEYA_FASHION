## � Quick Start

```bash
# Clone repository
git clone https://github.com/yourusername/seya-fashion.git

# Backend setup
cd backend
npm install
npm run dev

# Frontend setup (new terminal)
cd frontend
npm install
npm run dev
```

> **Note:** Configure `.env` files in both directories with your credentials before running.
